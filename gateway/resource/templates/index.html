合并为多渠道账号
同一个微信在不同渠道各扫出了一个 ID，合并后脚本只需要保留主账号，请求会在各渠道之间自动轮换。

      
脚本和面板里使用这个 ID；已是多渠道账号的可以继续补充渠道。

      

      
合并前会核对微信 unionid：不是同一个微信的账号会被拒绝，可以在结果里选择仍然合并。合并不会删除任何账号，卡片上随时可以拆分。

      

      

    

  
  
    

      
合并误新增账号
将误新增账号的授权移入原 ID，不按昵称自动判断身份。

      

      

      
保留原 ID 的代理、归属、备注、任务和推送设置，替换其登录授权并清理旧会话及授权链接。请确认两条记录属于你的同一微信；手动维护的来源 ID / 旧 OpenID 引用需要更新。

      
先预览，再确认合并。来源有专属任务时需先处理任务。

      

    

  
  
    

      

        

          
生成扫码链接

          
链接只可使用一次，生成后请直接交给授权人。

        

        
      

      

        

          
          允许同一微信逐个扫码，分别保存各渠道并归组。原账号 ID 保留，点击“完成授权”或到期后链接失效。
        

        

          
          
          切换前会说明影响，扫码成功后保留原账号 ID。
        

        

          
          
          范围 1 到 10080 分钟。二维码刷新不会消耗链接有效期。
