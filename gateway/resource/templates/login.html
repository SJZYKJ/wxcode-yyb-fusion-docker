版本更新

当前版本 —
  1. v13
    账号隔离真正落地 + 界面整体焕新

    修复「点运行一个账号却跑了全部」的问题：手动运行严格只跑选中的那一个账号，定时脚本只跑登录账号名下的账号，两条链路行为一致。安卓手机端（Xposed Hook）取码支持整体下线，只保留 Docker 部署与原生扫码协议。登录页与功能页视觉全面重做，普通用户界面不再出现任何管理入口，用户管理页仅管理员可访问。

  2. v10
    账号隔离分两档 + 脚本目录可见范围

    「运行」只跑你选中的那一个 code 账号；打开「定时」后按网关登录账号隔离，跑该登录账号名下的全部 code 账号，同一脚本只建一条任务、不会重复执行。管理员还能指定非管理员账号只能看到青龙里哪些文件夹下的脚本，看不到的脚本既列不出来、也无法运行或开定时。老版本遗留的「每个 code 账号一条、还启用着」的任务，打开运行管理时会自动收敛成一条登录账号级任务。

  3. v9
    「运行账号」真的只跑这一个账号了

    以前在网关上点「运行账号」，脚本会去网关枚举全部微信账号，于是把所有人的号都跑了一遍。现在网关建的任务只跑它自己那一个账号；你在青龙里直接运行同一个脚本不受影响，还是按青龙的全局 WECHAT_OPENIDS 取账号（写 ALL 就是全部账号）。

  4. v8
    脚本列表改看「脚本文件」，不再看定时任务

    以前这一页的脚本是从青龙的定时任务倒推出来的，于是你自己建的任务会被当成可用脚本，而同一个脚本既在青龙有全局任务、又被挂到账号上时，还会真的跑两遍。现在直接读青龙脚本目录里的脚本文件，并标出哪些脚本在青龙里已有全局任务；列表上方还能按目录筛选。面板没有这个接口时（老青龙、代代面板）会自动退回原来的方式，并在页面上说明。

  5. v7.1
    「账号运行管理」能列出你的脚本了

    这一页的脚本列表改成直接读青龙里的「全部定时任务」，不再要求任务目录事先配置成某个名字——以前漏配就一个脚本都显示不出来。列表为空时也会说清楚是「青龙里确实没有任务」还是「任务命令认不出脚本」。

  6. v6
    修好了「串号」隐患（建议升级）

    以前用普通账号登录网页后，能直接看到全部微信号——包括管理员的。现在网页登录只显示自己的账号，看不到别人的；青龙脚本带着令牌调用不受影响，照旧能取到全部账号的码。

更早：装上就默认安全（取码接口必须带令牌、陌生人抢注管理员被挡住、密码试错限速，v5）；取码接口支持访问令牌、双架构镜像与一键部署脚本（v4）；多个账号互相隔离（每人只看到自己扫码添加的微信）、每个微信号可单独关闭「脚本可读」、修复数据目录权限导致的启动失败。
