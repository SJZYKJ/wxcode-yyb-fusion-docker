版本更新

当前版本 —
  1. v16
    注册邮箱验证 + 用户批量删除

    注册时必须填写邮箱并通过邮箱验证码校验，验证码 10 分钟内有效、一次性使用、同一邮箱发送带频率限制，邮箱重复注册会被拒绝；服务端未配置邮件服务时直接拒绝注册，不会静默放行。用户管理页新增复选框与「删除所选」按钮，可勾选多个成员一次性删除，删除前二次确认，并保护当前登录账号与最后一名管理员不被误删。

  2. v15
    修复青龙新建文件夹内的脚本在网关看不到的问题

    青龙里新建的文件夹（脚本目录）现在能被网关照常识别，目录内的脚本会正确出现在「账号运行管理」列表中，不再出现脚本存在却列不出来的情况。

  3. v14
    控制台界面整体重构 + 管理入口修复

    统一设计系统：侧栏换成图标化导航（当前页高亮指示），卡片、按钮、表格全面升级质感与微动效；登录页改为居中卡片布局。修复普通用户登录后侧栏仍显示「用户管理」入口的权限显示错误——现在该入口仅管理员可见。

  4. v13
    账号隔离真正落地 + 安卓支持下线

    修复「点运行一个账号却跑了全部」的问题：手动运行严格只跑选中的那一个账号，定时脚本只跑登录账号名下的账号。安卓手机端（Xposed Hook）取码支持整体下线，只保留 Docker 部署与原生扫码协议。

  5. v10
    账号隔离分两档 + 脚本目录可见范围

    「运行」只跑选中的那一个 code 账号；打开「定时」后按网关登录账号隔离，同一脚本只建一条任务。管理员可指定非管理员只能看到放行目录下的脚本。
