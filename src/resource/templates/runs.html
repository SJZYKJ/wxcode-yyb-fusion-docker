上传的脚本没显示？

“全部脚本”来自已配置目录下的面板任务，单独上传文件不会自动入列。

  1. 将支持 YYB_SERVER 的脚本上传到管理员配置的 YYB_QINGLONG_REPO 目录。
  2. 在面板新建任务，命令例如 task 目录名/脚本.py，填写正确的 Cron。若仅供 YYB 按账号运行，请将这个原始任务设为禁用，避免重复执行。
  3. 回到本页点击“刷新状态”，在“全部脚本”中按名称或路径搜索，再为当前账号启用。

自建目录须加入 YYB_QINGLONG_REPO（多个目录以逗号分隔）并重启 YYB 服务；请保留原有目录。目录匹配不代表脚本已完成 YYB 协议适配。

检测到旧全局任务仍启用。 同一脚本可能被全局任务和账号任务重复执行，请先在青龙中停用对应全局任务。
运行范围：点「运行账号」只跑当前选中的那个 code 账号；打开「定时」后按网关登录账号隔离 —— 跑该登录账号名下的全部 code 账号，且同一脚本只建一条定时任务，不会重复执行。两种任务都会把任务前命令里的 WECHAT_OPENIDS 写死成对应范围，不会跑到别的登录账号的账号上。在青龙里直接运行同一个脚本不受影响，仍按青龙全局 WECHAT_OPENIDS（写 ALL 就是全部账号）。
